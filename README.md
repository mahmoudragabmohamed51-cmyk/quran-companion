# Quran Companion — رفيق الحفظ والتسميع

واجهة عربية RTL أولية تعمل كتطبيق ويب متجاوب (PWA).

## الموجود في النسخة الأولى
- لوحة متابعة بسيطة للحفظ والمراجعة.
- إضافة خطط حفظ مع اسم السورة ونطاق الآيات والنص الذي يضيفه المستخدم من مصحف موثوق.
- تسجيل صوتي محلي للتدريب الشخصي وتنزيل التسجيل.
- اختبار إكمال النص من الخطط المحفوظة (مطابقة نصية فقط).
- سجل جلسات المراجعة والأنشطة.
- رسائل تحفيزية متنوعة وإعداد وقت تذكير محلي.
- ملف manifest وخدمة Service Worker للتثبيت والتخزين المؤقت الأساسي.

## ملاحظات مهمة
- لا يحتوي المشروع حاليًا على قاعدة بيانات مصحف كاملة. أضف النص القرآني فقط من مصدر موثوق ومراجع.
- لا يصحح التطبيق التلاوة أو التجويد آليًا، ولا يُعد بديلًا عن المعلم المتقن.
- بيانات هذه النسخة محفوظة محليًا في المتصفح (localStorage)، ولا تتم مزامنتها بين الأجهزة.
- تذكير المتصفح المحلي لا يضمن إرسال إشعارات عند إغلاق التطبيق. إشعارات Push الحقيقية تحتاج HTTPS ومزوّد Push وخادمًا/وظيفة خلفية وإدارة اشتراكات.
- هذا المشروع ليس تطبيق Android أصليًا بعد؛ يمكن لاحقًا تغليفه أو بناء تطبيق Android بعد استكمال الاختبار.

## النشر عبر GitHub Pages
